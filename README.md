# Apollon, die Webseite

Hier liegt der veroeffentlichte Stand von **apollon.eu.com**.

Der Server holt sich die Dateien von hier ab. Was hier liegt, ist online.

## Was hier drin ist

Nur die fertigen Seiten: HTML, Stilvorlage, Bilder, Schriften.
Alles davon ist ohnehin oeffentlich, jeder Besucher laedt genau diese Dateien.

## Was hier bewusst nicht drin ist

Keine PHP-Dateien, keine Zugangsdaten, keine Kennungen,
keine Rueckmeldungen und keine Texte aus dem Bearbeitungsbereich.

## stand.json

Ein Verzeichnis aller Dateien mit ihrer Pruefsumme.
Der Abholdienst auf dem Server vergleicht damit, was sich geaendert hat,
und laedt nur das Noetige nach.
